# NewEye downloads

Installers for NewEye, the desktop app that shows every AI coding session about a project in
one place. Download the newest version from the Releases page:

https://github.com/offleg/neweye-releases/releases/latest

- Mac with an Apple chip (M1 and later): the `arm64.dmg` file
- Mac with an Intel chip: the `x64.dmg` file
- Windows: the `.exe` file
- Linux: the `.AppImage` file

The app is not signed yet. The first time you open it, Mac asks you to right-click the app and
choose Open; Windows shows "More info" then "Run anyway". The code lives in a private repository;
this one only holds the files.
